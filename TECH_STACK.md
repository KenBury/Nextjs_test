# Technology Stack - Nextjs_test

## Core Framework & Language
* **Framework:** Next.js 15+ (App Router)
* **Language:** TypeScript 5+
* **Runtime:** Node.js (v20+)

## Frontend UI & Styling
* **UI Library:** React 19
* **Styling:** CSS Modules / Vanilla CSS / TailwindCSS
* **Linting & Formatting:** ESLint, TypeScript Compiler (`tsc`)

## Backend API & Services
* **API Pattern:** Next.js App Router Route Handlers (`app/api/.../route.ts`)
* **Server Interactivity:** React Server Actions (`use server`)
* **Validation:** Zod

## DevOps & Build
* **Package Manager:** `npm`
* **Build Script:** `npm run build`
* **Lint Script:** `npm run lint`
